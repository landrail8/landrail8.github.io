# landrail8.github.io

Personal site with two locale routes:

- `https://landrail8.github.io/ru/` — canonical Russian content
- `https://landrail8.github.io/en/` — generated English content

The root route redirects to `/ru/`.

Подробная русскоязычная инструкция по редактированию, локальному просмотру, переводу и деплою находится в [`LOCALIZATION.md`](LOCALIZATION.md).

## Editing content

Edit only [`_data/locales/ru.yml`](_data/locales/ru.yml). Keep the `id` of an existing list item stable: translation memory uses it to recognize the same content block even when items are reordered.

The English file is generated by `scripts/translate.rb`. Existing translations live in `.translation-memory/en.yml`; a block is sent for translation only when it is new or its Russian source text has changed. Identical Russian text is also reused across different items. Entries have one of two statuses:

- `machine` — generated automatically and awaiting review
- `approved` — reviewed by a person

Both statuses are reused while the Russian source hash stays unchanged. This prevents approved text from being translated again.

Review and correct generated text in `.translation-memory/en.yml`, then change its status to `approved`. The generated `_data/locales/en.yml` file is rebuilt from that memory.

## Deployment translation

Add an Actions secret named `OPENAI_API_KEY`. Optionally set the repository variable `OPENAI_TRANSLATION_MODEL`; the default is `gpt-6-astra`.

On every push to `master`, `.github/workflows/deploy.yml`:

1. translates only new or changed Russian blocks;
2. updates the English locale and translation memory;
3. commits those generated changes with `[skip ci]`;
4. builds and deploys both routes to GitHub Pages.

To verify locally without calling the API:

```sh
ruby scripts/translate.rb --check
```

To approve all current machine translations after review:

```sh
ruby scripts/translate.rb --approve-all
```

The translation script uses the OpenAI Responses API with Structured Outputs and has no external Ruby dependencies.
